# بدر التلاوات — تطبيق الآيفون

تطبيق SwiftUI يقرأ كل محتواه من bawazirquran.com (نفس واجهة الموقع وتطبيق أندرويد).

## البناء
كل رفع على `main` يبني التطبيق تلقائيًا على GitHub Actions (أجهزة ماك) وينتج ملف `BadrTilawat.ipa` غير موقّع
في صفحة الـ Action ← **Artifacts** ← `BadrTilawat-ipa`.

## التثبيت على الآيفون (Sideloadly)
1. على الكمبيوتر: ثبّت iTunes (من موقع أبل) و Sideloadly (sideloadly.io).
2. نزّل `BadrTilawat-ipa` من صفحة الـ Action وفك الضغط لتحصل على `BadrTilawat.ipa`.
3. وصّل الآيفون بالكابل، وافتح Sideloadly، واسحب الملف إليه، واكتب Apple ID، ثم **Start**.
4. على الآيفون: الإعدادات ← عام ← إدارة الجهاز (VPN وإدارة الأجهزة) ← اختر حسابك ← **وثوق**.
5. الإعدادات ← الخصوصية والأمان ← **وضع المطوّر** ← تشغيل (ثم إعادة تشغيل الهاتف).
6. التطبيق يعمل ٧ أيام بحساب أبل المجاني — كرر الخطوة ٣ للتجديد (بياناتك تبقى).
